EUROPLAN CWPS - MOBILE OFFLINE PACKAGE

1. Extract the complete ZIP using Files by Google or another ZIP application.
2. Open CWPS_Mobile.html and choose Chrome or another modern browser.
3. Keep the attachments folder beside CWPS_Mobile.html.

The viewer, forms, search, document text and risk scoring are embedded in the HTML.
Drawings, references and formatted RA/MS files remain under attachments at original quality.
Some Android file managers or browsers may restrict links from local HTML to adjacent attachments.
If an attachment link is blocked, open that file directly from the attachments folder.

NEW: IMPORT FEEDBACK JSON
Each reviewer's device can export its own entries with Download JSON.
Use "Import feedback JSON" (in a document's record toolbar) to bring one
or more of those files back in. Only the fields present in the imported
file(s) are updated; every other locally saved entry on that device -
in that document or any other - is left untouched. You can select
several reviewers' files at once.
